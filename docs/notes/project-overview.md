# StitchSmith — Project Overview

> **Status:** New project — no source code yet. This overview reflects the planned tech stack and architecture from the v1 design at `docs/plans/2026-05-20-stitchsmith-tool-roll-generator-design.md`.

## Tech Stack
- React (18+) + TypeScript
- Vite (build tool / dev server)
- Tailwind CSS
- shadcn/ui (Radix primitives, copy-in components)
- lucide-react (icons)
- SVG (rendering — no canvas, no PDF lib in v1)
- LocalStorage (state persistence)

## Architecture
StitchSmith is a static-hostable single-page app for generating custom sewing patterns from measured input. The first module is the **Tool Roll Generator**. Architecture is three layers:

1. **UI Shell** — React components (shadcn/ui + Tailwind) for tool table, settings, preview, exports.
2. **Generator Layer** — pure TypeScript functions that take tools + settings and return a render-ready `ToolRollLayout` model. No React, no DOM, easily unit-testable.
3. **SVG Renderer** — consumes the layout model, emits SVG fragments for live preview and exports.

Design philosophy: patterns are **generated geometry**, not hand-drawn assets. Geometry math lives in pure functions; React components only render.

A `PatternGenerator<TSettings, TInput, TLayout>` interface is defined in v1 so future modules (packing cubes, zip pouches, stuff sacks, roll-top bags, tool aprons) plug in without UI restructure.

## Key Patterns (planned)
- **Generated-geometry layered architecture** — pure calculator → layout model → SVG renderer.
- **Generator registry** — extensible via shared interface; v1 ships one generator.
- **Internal millimeter units** — all geometry and storage in mm; UI may display inches via conversion helpers.
- **SVG-first rendering** — vector preview + vector export; no canvas, no PDF.
- **LocalStorage + JSON I/O** — no backend, no cloud sync; debounced auto-save; JSON import/export with schema validation.
